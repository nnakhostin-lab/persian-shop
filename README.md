# کارگاه صنایع‌دستی — فروشگاه نمونه با Next.js

یک پروژه‌ی Next.js (App Router + TypeScript + Tailwind) که فهرست کالا را نشان می‌دهد،
امکان افزودن به سبد خرید را می‌دهد و سبد را در یک پنل کناری نمایش می‌دهد.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

## ساختار

- `data/products.ts` — لیست کالاها (برای اتصال به یک API واقعی، این فایل را با فراخوانی سرور جایگزین کنید)
- `context/CartContext.tsx` — منطق سبد خرید (افزودن، حذف، تغییر تعداد) با ذخیره‌سازی در `localStorage`
- `components/ProductCard.tsx` — کارت هر کالا با دکمه‌ی افزودن به سبد
- `components/CartDrawer.tsx` — پنل کناری سبد خرید
- `components/Header.tsx` — هدر با دکمه‌ی نمایش سبد و تعداد اقلام

## نکات

- جهت صفحه به‌صورت پیش‌فرض راست‌به‌چپ (`dir="rtl"`) تنظیم شده است.
- فونت مورد استفاده Vazirmatn از طریق `next/font/google` بارگذاری می‌شود.
- تصاویر کالا به‌صورت گرادیان رنگی جایگزین شده‌اند؛ برای تصاویر واقعی می‌توانید در
  `data/products.ts` فیلد تصویر اضافه کرده و در `ProductCard` از `next/image` استفاده کنید.
